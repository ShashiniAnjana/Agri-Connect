# AgriConnect — Modern Website Redesign

A responsive, modern HTML/CSS/JavaScript redesign for the AgriConnect Sri Lankan agriculture marketplace concept.

## Run it

1. Extract the folder.
2. Open `index.html` in a modern browser. For the best local development experience, use VS Code's Live Server extension.

No build tools or npm packages are required.

## Included interactions

- Responsive mobile navigation
- Product search and category filters
- Add-to-basket count with feedback messages
- Favorite buttons
- Smooth in-page navigation
- Keyboard shortcut: `Ctrl/Cmd + K` focuses marketplace search

## Project notes

- Product photos and the original icon sprite / hero asset were taken from the supplied AgriConnect archive. The product photos are reused in the marketplace and hero area.
- `assets/logo.svg` is a lightweight AgriConnect wordmark icon created for this redesign because the supplied `favicon.svg` was a generic Vite-style icon, not an AgriConnect logo.
- Product names, locations, prices, and basket interactions are front-end demo content. This static version is not connected to the original login, database, orders, messaging, or AI services.
